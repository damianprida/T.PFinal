
Recreación funcional de la interfaz de WhatsApp Web utilizando React. 
Construí una Single Page Application (SPA) dinámica,
gestionando estados globales y persistencia de datos para simular una experiencia de chat real.

Tecnologías y herramientas utilizadas:
React 19 (Vite) React Router Dom (Enrutamiento y parámetros de búsqueda) 
Context API y Hooks (useState, useContext, useEffect) 
JavaScript (ES6+) CSS3 (Flexbox, Grid, CSS Variables para tema claro/oscuro) 
LocalStorage (Persistencia de datos del usuario)
